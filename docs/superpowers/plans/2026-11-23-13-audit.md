# Implementation Plan: Prompt 13 — Audit Log

**Goal:** Create a trustworthy, append-only record of system activity with advanced filtering, CSV export, and an interactive UI.

---

## Phase 1: Configuration & Schemas
- [ ] Create `config/audit.yaml` (`audit_page_size_default: 50`, `audit_page_size_max: 200`, `audit_export_max_rows: 5000`, `audit_retention_days: 90`).
- [ ] Extend `backend/app/core/config.py` `Settings` with audit configuration fields and load `config/audit.yaml`.
- [ ] Create `backend/app/schemas/audit.py` with `AuditLogResponse` and `AuditLogsListResponse`.
- [ ] Register schemas in `backend/app/schemas/__init__.py`.

## Phase 2: Audit Service & Export Streamer
- [ ] Create `backend/app/services/audit_service.py`:
  - `list_audit_logs(db, ...)`: filtered query with user, action, target_type, target_id, result, since, until, page, page_size, sort_order.
  - `get_audit_log(db, audit_id)`: fetch single record.
  - `stream_audit_export_csv(db, ...)`: async generator streaming CSV rows with chunking and safety row cap.
- [ ] Register in `backend/app/services/__init__.py`.

## Phase 3: API Endpoints & Router
- [ ] Create `backend/app/api/v1/audit.py`:
  - `GET /audit` (and `/api/v1/audit`): Admin-only list endpoint.
  - `GET /audit/export` (and `/api/v1/audit/export`): Admin-only streaming CSV export.
  - `GET /audit/{audit_id}`: Admin-only single log detail.
- [ ] Register router in `backend/app/api/v1/router.py` and `backend/app/main.py`.

## Phase 4: Backend Unit Tests
- [ ] Create `backend/tests/test_audit_api.py`:
  - Authentication (401) and Authorization (403 for viewer/operator, 200 for admin).
  - Filter testing (user, action, target, result, since, until).
  - Pagination boundary tests.
  - CSV export format, headers, and filter validation.
  - Append-only tests (POST/PUT/DELETE return 405).
  - Parameterized verification that container actions, compose actions, resource deletions, and terminal actions create audit records.
- [ ] Run `python -m pytest -q backend` and verify 100% pass rate.
