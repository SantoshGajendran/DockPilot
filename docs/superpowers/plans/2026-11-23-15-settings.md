- [ ] Export schemas in `backend/app/schemas/__init__.py`.

## Phase 3: Service Layer & Background Retention
- [ ] Create `backend/app/services/settings_service.py`:
  - `get_settings()`: Reads defaults from `get_settings()` + merges DB overrides from `SystemSetting`.
  - `update_settings()`: Validates bounds, persists overrides to DB, hot-patches active `get_settings()` memory, writes audit log.
  - `get_storage_usage()`: Queries `pg_database_size`, `pg_total_relation_size`, table row counts.
  - `run_retention()`: Aggregates metrics older than `metrics_rollup_age_hours` into `metric_rollups`, deletes raw rolled-up metrics, deletes expired metrics/events/audit/sessions, logs audit entry.
- [ ] Register `SettingsService` in `backend/app/services/__init__.py`.
- [ ] Add dependency provider `get_settings_service` in `backend/app/api/deps.py`.

- [ ] Mount router in `backend/app/api/v1/router.py` and root alias `/settings` in `backend/app/main.py`.
