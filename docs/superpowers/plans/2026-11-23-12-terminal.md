# Implementation Plan: Prompt 12 — Web Terminal

**Goal:** Implement safe admin-only shell inside a container over WebSocket (`/containers/{id}/exec`) with feature flag gating, session limits, idle timeout, resize support, transcript recording, and an interactive xterm.js tab on Container Detail page.

---

- [ ] Task 1.1: Create `config/terminal.yaml` and update `backend/app/core/config.py` `Settings` with terminal configuration.

- [ ] Task 1.3: Generate Alembic migration `0007_terminal_sessions.py` for table `terminal_sessions`.
