# Login Page & Authentication Subsystem (Prompt 01) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Secure sign-in with role-aware sessions, Argon2 password hashing, dual JWT/httpOnly cookie token management, lockout brute-force defense, first-run bootstrap, and Angular `/login` page with silent refresh.

**Architecture:** Layered backend auth module: Argon2id password hashing + PyJWT token engine in `core/security.py`, schemas in `schemas/auth.py`, service orchestration with audit logging in `services/auth_service.py`, FastAPI routers in `api/v1/auth.py`, and startup admin bootstrap in `main.py`. Angular 19 standalone `/login` route with reactive forms, password visibility toggle, loading states, silent refresh on boot via `AuthService.init()`, and session-expired modal handling.

**Tech Stack:** Python 3.12+, FastAPI, Argon2 (`argon2-cffi`), PyJWT, SQLAlchemy 2 Async, pytest, Angular 19, TypeScript, Angular Material, RxJS.

```python
import uuid
from datetime import datetime, timedelta, timezone
from typing import Any, Dict
from argon2 import PasswordHasher
from argon2.exceptions import VerifyMismatchError
import jwt
from app.core.config import get_settings

hasher = PasswordHasher(
    time_cost=2,
    memory_cost=65536,
    parallelism=1,
    hash_len=32,
)

def hash_password(password: str) -> str:
    return hasher.hash(password)

def verify_password(plain_password: str, hashed_password: str) -> bool:
    try:
        return hasher.verify(hashed_password, plain_password)
    except (VerifyMismatchError, Exception):
        return False

def create_access_token(user_id: uuid.UUID, username: str, role: str) -> str:
    settings = get_settings()
    now = datetime.now(timezone.utc)
    expire = now + timedelta(minutes=settings.jwt_access_expire_minutes)
    payload = {
        "sub": str(user_id),
        "username": username,
        "role": role,
        "type": "access",
        "iat": now,
        "exp": expire,
    }
    return jwt.encode(payload, settings.jwt_secret, algorithm="HS256")

def create_refresh_token(user_id: uuid.UUID) -> str:
    settings = get_settings()
    now = datetime.now(timezone.utc)
    expire = now + timedelta(days=settings.jwt_refresh_expire_days)
    payload = {
        "sub": str(user_id),
        "token_id": str(uuid.uuid4()),
        "type": "refresh",
        "iat": now,
        "exp": expire,
    }
    return jwt.encode(payload, settings.jwt_secret, algorithm="HS256")

def decode_token(token: str) -> Dict[str, Any]:
    settings = get_settings()
    return jwt.decode(token, settings.jwt_secret, algorithms=["HS256"])
```
